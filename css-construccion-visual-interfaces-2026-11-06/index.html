01 · Conceptos

¿Qué es CSS?

CSS significa Cascading Style Sheets (hojas de estilo en cascada). Controla cómo se ven los elementos de una página.

HTML

Estructura

Define títulos, párrafos, imágenes y botones.

CSS

Presentación

Define colores, tamaños, bordes y posiciones.

JS

Interacción

Permite responder a clics y otras acciones.

Ejemplo cotidiano: HTML construye la casa; CSS decide la pintura, distribución y decoración.
02 · Primeros pasos

¿Cómo escribimos CSS?

Una regla CSS selecciona un elemento y establece una o varias propiedades.

h1 { color: darkred; font-size: 32px; text-align: center; }

Selector → h1 · Propiedades → color, font-size, text-align

Resultado

¡Hola, CSS!

Recuerda: cada propiedad se escribe como nombre: valor;.
03 · Integración

Tres formas de aplicar CSS

En línea

<p style="color:red"> Hola </p>

Útil para un cambio puntual.

Interno

<style> p {color:red;} </style>

Dentro del archivo HTML.

Externo

<link rel="stylesheet" href="estilos.css">

Recomendado para proyectos organizados.

En esta clase usaremos CSS interno para practicar en un solo archivo.
04 · Selectores

¿A qué elemento queremos dar estilo?

/* Por etiqueta */ p { color: #333; } /* Por clase */ .tarjeta { background: #eee; } /* Por identificador */ #titulo { font-size: 32px; }

Cómo se relacionan

<h1 id="titulo">Tienda</h1> <p>Bienvenidos</p> <div class="tarjeta"> Producto destacado </div>

. representa una clase y # representa un identificador.

05 · Diseño visual

Colores y fondos

CSS permite elegir colores por nombre, código hexadecimal o valores RGB.

#a91e30

Color de énfasis.

#182334

Texto y contraste.

#f5f7fa

Fondo suave.

body { background-color: #f5f7fa; color: #182334; } button { background-color: #a91e30; color: white; }
06 · Legibilidad

Tipografía y jerarquía

body { font-family: Arial, sans-serif; line-height: 1.6; } h1 { font-size: 36px; } p { font-size: 17px; }

07 · Espaciado

Modelo de caja: margin y padding

.caja { margin: 20px; padding: 25px; border: 2px solid #a91e30; border-radius: 12px; }

Margin: espacio exterior. Padding: espacio interior. Border: borde del elemento.

Contenido

El padding separa el texto del borde.

Zona exterior: margin

08 · Componentes

Diseñemos un botón

.boton { background: #a91e30; color: white; padding: 12px 24px; border: none; border-radius: 8px; cursor: pointer; } .boton:hover { background: #821325; }
Pruébalo con el cursor
El estado :hover se activa al pasar el cursor sobre un elemento.

10 · Distribución

Flexbox: organizar elementos

Flexbox ayuda a alinear elementos en filas o columnas sin calcular posiciones manualmente.

.contenedor { display: flex; justify-content: space-between; align-items: center; gap: 12px; }
InicioProductosContacto
Piensa en el menú de una página: sus opciones deben alinearse y mantener espacios consistentes.
11 · Adaptación

Diseño responsive

Una interfaz responsive cambia su distribución según el tamaño de la pantalla.

.productos { display: grid; grid-template-columns: repeat(3, 1fr); gap: 15px; } @media (max-width: 700px) { .productos { grid-template-columns: 1fr; } }

15 · Evaluación

¿Qué propiedad utilizarías?

Separar el texto del borde

Respuesta: padding.

Colocar elementos en una fila

Respuesta: display: flex.

Redondear esquinas

Respuesta: border-radius.

Cambiar color del texto

Respuesta: color.

Cambiar el fondo

Respuesta: background.

Adaptarse al celular

Respuesta: @media.

16 · Cierre

Hoy construimos una interfaz visual

Ya puedes combinar HTML y CSS para diseñar páginas con estructura, jerarquía, componentes y distribución adaptable.

Lo que debes recordar

  • HTML organiza el contenido
  • CSS controla la apariencia
  • Clases reutilizan estilos
  • Flexbox y Grid organizan elementos
  • Media queries adaptan la página
