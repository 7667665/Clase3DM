¿Qué es una página web?

Lo que vemos

Textos, imágenes, enlaces, menús y botones organizados dentro de un navegador.

HTML define el contenido. CSS define la apariencia. JavaScript añade comportamiento.

Lo que escribimos

HTML → estructura
CSS → colores y tamaños
JavaScript → interacciones

Navegador → muestra la página

¿Qué significa index.html?

index: nombre habitual de la página principal.

.html: extensión que identifica un documento HTML.

Podemos abrirlo directamente en Chrome, Edge u Opera.

34–40 MIN

Una página completa en código

<header>Mi tienda</header> <nav>Inicio | Productos</nav> <main> <h1>Bienvenidos</h1> <section> <h2>Productos</h2> <p>Conoce el catálogo.</p> </section> </main> <footer>© 2026 Mi tienda</footer>

¿Qué hace cada etiqueta?

header: encabezado de la página o sección.

nav: enlaces de navegación.

main: contenido principal.

section: agrupación temática.

footer: información final.

h1, h2, p: títulos y párrafos.

40–48 MIN

La estructura obligatoria de HTML

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <title>Mi primera web</title> </head> <body> <h1>Hola, mundo</h1> </body> </html>

Explicación línea por línea

DOCTYPE: indica HTML moderno.

html lang: raíz del documento e idioma.

head: datos de configuración no visibles en la página.

meta charset: admite caracteres como ñ y tildes.

title: texto de la pestaña.

body: contenido visible.

48–56 MIN

Etiquetas que utilizaremos hoy

<h1>Mi sitio</h1> <h2>Sobre mí</h2> <p>Soy estudiante del ITQ.</p> <a href="https://www.google.com">Visitar Google</a> <img src="foto.jpg" alt="Mi foto">

h1: título principal. h2: subtítulo.

p: párrafo de texto.

a: enlace a otra página.

href: dirección del enlace.

img: imagen. src: ruta de la imagen. alt: descripción alternativa.

Observa que algunas etiquetas tienen apertura y cierre; img no necesita etiqueta de cierre.

65–72 MIN

¿Por qué usamos Bootstrap?

HTML sin estilos

El contenido funciona, pero el navegador aplica una apariencia básica.

<button>Guardar</button>

HTML con Bootstrap

Bootstrap ofrece estilos ya preparados que podemos aplicar con clases.

<button class="btn btn-danger">Guardar</button>

class: asigna clases de estilo. btn: estilo de botón. btn-danger: variante roja.

72–80 MIN

Conectamos Bootstrap

Agrega esta línea dentro de <head>

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

Esta línea descarga los estilos de Bootstrap desde Internet.

¿Qué significa?

link: conecta un recurso externo.

href: ubicación del archivo CSS.

rel="stylesheet": indica que es una hoja de estilos.

Para esta clase usaremos Bootstrap 5.3.3. La conexión CDN necesita Internet.

80–89 MIN

Contenedores y colores

<div class="container mt-4"> <h1 class="text-danger">Hola ITQ</h1> <p class="text-muted">Mi página web</p> </div>

div: agrupa elementos.

container: centra y limita el ancho del contenido.

mt-4: margen superior.

text-danger: texto rojo.

text-muted: texto de tono atenuado.

Bootstrap funciona agregando clases a las etiquetas HTML que ya conocemos.

89–98 MIN

Botones y tarjetas con Bootstrap

<button class="btn btn-danger">Enviar</button> <div class="card p-3"> <h2>Mi perfil</h2> <p>Estudiante del ITQ</p> </div>

btn: apariencia de botón.

btn-danger: color rojo.

card: caja visual con borde y fondo.

p-3: espacio interior.

h2 y p: siguen siendo etiquetas HTML normales.

98–105 MIN

Dos columnas que se adaptan

<div class="container"> <div class="row"> <div class="col-md-6">Izquierda</div> <div class="col-md-6">Derecha</div> </div> </div>

row: crea una fila.

col-md-6: ocupa 6 de las 12 columnas disponibles desde pantallas medianas.

En pantallas pequeñas, las columnas se apilan.
